💡 使用建议：导出文件包含你的全部数据（任务状态、口语进度、复盘记录等）。请妥善保管，不要分享给他人。导入会覆盖当前数据，操作前请确认。
☁️ 云端同步（跨设备）

连接 Supabase 云端数据库后，电脑端和手机端数据自动同步。换设备登录账号即可恢复全部数据。

📋 首次使用，请按以下步骤设置（约 5 分钟）：
  1. 打开 Supabase 官网，点击「Start your project」注册（可用 GitHub 账号一键登录）
  2. 点击「New Project」创建项目，名称随意填（如 my-workbench），设置数据库密码
  3. 等待项目创建完成（约 1-2 分钟），进入项目后点击左侧「SQL Editor」
  4. 将下方建表代码粘贴进去，点击「Run」执行：
CREATE TABLE IF NOT EXISTS workbench_data ( user_id UUID REFERENCES auth.users(id) ON DELETE CASCADE, data_key TEXT NOT NULL, data_value JSONB, updated_at TIMESTAMPTZ DEFAULT NOW(), PRIMARY KEY (user_id, data_key) ); ALTER TABLE workbench_data ENABLE ROW LEVEL SECURITY; CREATE POLICY "Users manage own data" ON workbench_data FOR ALL USING (auth.uid() = user_id) WITH CHECK (auth.uid() = user_id);
  • 点击左侧「Project Settings」→「API」，复制 Project URL 和 anon public key
  • 将这两个值填入下方输入框，点击「连接」

    ℹ️ 数据安全说明
    📱 本地存储
    数据存在浏览器 localStorage。同一浏览器下关闭/重开/刷新都保留。清除浏览器数据、无痕模式、换设备会丢失。
    💾 导出备份
    将本地数据下载为 JSON 文件。文件在你自己的设备上，你完全掌控。建议定期备份。
    ☁️ 云端同步
    数据加密传输到 Supabase 云端（AWS 数据中心）。免费额度 500MB，个人使用绰绰有余。可随时导出或删除。
    🔄 换设备找回
    新设备打开网页 → 数据同步页面 → 登录同一账号 → 点击「从云端拉取」→ 全部数据恢复。

    ⚙️ API 设置
    当前支持 DeepSeek（OpenAI 兼容格式）。后续可扩展其他平台。
    常用模型：deepseek-chat（日常对话，速度快）· deepseek-reasoner（深度思考，适合复杂分析）
    DeepSeek 官方地址：https://api.deepseek.com。一般不需要修改。
    在 DeepSeek 开放平台创建，以 sk- 开头。输入后默认隐藏，点眼睛图标可临时查看。
    📖 配置指南（一步步来）
    1. 打开 DeepSeek 开放平台：https://platform.deepseek.com/api_keys
    2. 登录你的 DeepSeek 账号（没有就注册一个，新用户有免费额度）
    3. 点击「创建 API Key」，给它起个名字（如"工作台"），复制生成的 Key（以 sk- 开头）
    4. 回到本页面，把 Key 粘贴到上方「API Key」输入框
    5. 模型名称填 deepseek-chat（日常对话）或 deepseek-reasoner（深度思考）
    6. API 地址保持默认 https://api.deepseek.com 不变
    7. 点击「保存配置」，然后点「测试连接」——看到绿色✅就说明成功了
    8. 如果想换 Key：清空输入框，粘贴新 Key，再点「保存配置」
    9. 如果想删除 Key：点「清除配置」，确认后 Key 会从浏览器中彻底删除
    ⚠️ 安全提示
    • API Key 存储在你当前浏览器的 localStorage 中，是明文存储，仅限本设备本浏览器
    • 不要在公共电脑、网吧等共享设备上配置 API Key
    • 你的 Key 不会被包含在「导出备份」和「云端同步」中，不会上传到任何第三方服务
    • Key 只会发送给你填写的 API 地址（DeepSeek 官方接口），不会发送到其他地方
    • 如果怀疑 Key 泄露，请立即去 DeepSeek 平台删除该 Key 并重新创建
